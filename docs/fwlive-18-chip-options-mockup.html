fwlive filter chips — include vs exclude

Mockup for #18. Same sample filters on each option. Invert (≠) and remove (×) stay as today. In the app these are selectable via a compact toolbar Chip style dropdown (Labels / Symbols / Tone); default is Labels (A + light B). Toggle light/dark for LuCI-ish themes.

Option A → Labels (default) — polarity + light B

App default (labels). Include: solid chip, small is, subtle left accent. Exclude: dashed, bold not, strikethrough value, light leading ≠. No traffic-light colors.

Include chips
is proto: tcp × is action: DROP × is src: 10.0.0.5 × Clear all
Exclude chips
≠ proto: not tcp × ≠ action: not DROP × ≠ src: not contains 10.0.0.5 × Clear all

Default in product. Choose Labels in the Chip style dropdown.

Option B → Symbols

Include: leading = + solid left accent. Exclude: leading ≠ on the chip + dashed. Invert button still toggles.
